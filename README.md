# awenv

## 环境配置

just 是保存和运行命令的运行器。

1. 用 uv 安装（推荐）

```bash
# On macOS、Linux、WSL and Windows Git Bash.
curl -LsSf https://astral.sh/uv/install.sh | sh
uv tool install rust-just
```

2. 用 cargo 安装

```bash
# 跨平台（cargo）
cargo install just
```

## 使用指南

### 安装常用工具（CLI 工具 + GUI 工具下载地址）

```bash
just setup
```
